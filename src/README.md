# Paradise Nursery Shopping Application

An online plant shopping web application built with React, Vite, and Redux Toolkit.

## Features
- **Landing Page**: Welcome banner, company overview, and Get Started CTA.
- **Product Catalog**: Air-purifying, aromatic, and medicinal plants categorized with pricing and descriptions.
- **Shopping Cart**: Real-time cart badge counter, quantity adjustment (+/-), individual item subtotal, cart total calculation, and item removal.

## Tech Stack
- React 18
- Redux Toolkit (State Management)
- Vite
